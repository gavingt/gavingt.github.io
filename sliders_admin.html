Slider Demo photos

Drag cards to change the order. Drop a photo on either half of a card to replace it, or click a card to preview it and edit its description (shown only on this page). Untick On to keep a pair here without showing it. The slider shows the first 28 pairs that are on; any more wait here until a place opens up. Changes stay on this page until you publish them. The iOS and Android apps and sliders.html all read this list, and hosts see a published change within about 10 minutes.

Connect to GitHub

Publishing commits to the gavingt.github.io repo, so this page needs a GitHub token. It's saved only in this browser.

  1. Open New fine-grained token.
  2. Under Repository access, choose Only select repositories and pick gavingt.github.io.
  3. Under Permissions, set Contents to Read and write, and Pages to Read-only (used to tell you when a change is live).
  4. Generate the token and paste it below.
